# SPlayer iOS适配计划

## 1. 项目现状分析
- 基于 Electron + Vue 3 + TypeScript 的音乐播放器
- 已实现部分跨平台支持，使用 isElectron 等环境检测
- 音频播放引擎：MPV（Electron 专用）、FFmpeg、HTML5 Audio Element
- UI 使用 Naive UI 组件库，桌面端布局（侧边栏 + 导航栏 + 主内容）
- 已分离部分平台特定代码，使用 IPC 通信

## 2. 适配方案
使用 **Capacitor** 作为跨平台框架，将现有 Web 应用转换为原生 iOS 应用。Capacitor 更适合此类迁移，因为它：
- 支持将现有 Web 应用直接包裹为原生应用
- 提供丰富的原生 API 插件
- 与 Vue 3 良好集成
- iOS 支持成熟

## 3. 实施步骤

### 3.1 环境配置与依赖添加
- 添加 Capacitor 核心依赖
- 配置 iOS 构建环境
- 安装必要的 Capacitor 插件（音频、文件系统、媒体会话等）

### 3.2 平台特定代码分离
- 完善环境检测机制（isCapacitor、isIOS 等）
- 重构 IPC 通信层，支持 Capacitor 插件调用
- 确保非 Electron 环境下能正常初始化和运行

### 3.3 移动端 UI 适配
- 实现响应式布局，适配不同屏幕尺寸
- 优化触摸交互，添加移动端手势支持
- 调整导航结构，适配移动端导航模式
- 优化播放控件，适配移动端操作习惯

### 3.4 音频播放引擎适配
- 确保 FFmpeg 和 HTML5 Audio Element 引擎在 iOS 上正常工作
- 移除 iOS 环境下对 MPV 引擎的依赖
- 实现 iOS 后台音频播放支持

### 3.5 iOS 特定功能实现
- 媒体会话集成（锁屏控制、控制中心支持）
- 通知中心集成
- 文件系统访问权限处理
- 音频播放权限处理
- 后台任务管理

### 3.6 测试与优化
- 在 iOS 模拟器和真机上进行测试
- 修复 iOS 平台特定问题
- 优化性能和用户体验
- 确保应用符合 App Store 审核要求

## 4. 预期成果
- 一个功能完整的 iOS 音乐播放器应用
- 与桌面版 SPlayer 共享核心代码
- 支持在线音乐播放、本地音乐管理、歌词显示等核心功能
- 良好的移动端用户体验
- 符合 App Store 审核要求

## 5. 风险评估
- **性能问题**：iOS 设备性能差异大，需要优化
- **权限限制**：iOS 对后台运行和文件访问限制严格
- **API 差异**：部分 Web API 在 iOS WKWebView 中支持有限
- **App Store 审核**：需要确保应用符合审核要求

## 6. 技术栈更新
- **新增依赖**：Capacitor Core、Capacitor iOS、Capacitor 音频插件、Capacitor 文件系统插件等
- **开发工具**：Xcode、iOS 模拟器

## 7. 实施优先级
1. 环境配置和依赖添加
2. 平台特定代码分离
3. 音频播放引擎适配
4. 移动端 UI 适配
5. iOS 特定功能实现
6. 测试与优化
